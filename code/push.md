# `push`

`push(direction)`
Push the mushroom block under the drone.

You cannot push bocks upwards.

returns `True` if the block was pushed, `False` otherwise.

takes `200` ticks to execute if the block was pushed, `1` tick otherwise.

example:
`push(North)`

Source: `EN/Strings/code_tooltips.txt`, `code_tooltip_push`.
