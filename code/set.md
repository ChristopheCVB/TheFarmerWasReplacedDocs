# `set`

`set(collection = None)`
Creates a new set.
If `collection` is None, it creates an empty set.
If `collection` is a collection of values, it creates a new set with those values in it.

returns a set.

takes `1 + len(collection)` ticks to execute.

example:
`new_set = set((1,2,3))`
