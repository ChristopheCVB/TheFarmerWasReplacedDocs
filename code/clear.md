# `clear`

`clear()` 
Removes everything from the farm, moves the drone back to position `(0,0)` and changes the hat back to the straw hat.

returns `None`

takes `200` ticks to execute.

example:
`clear()`

Source: `EN/Strings/code_tooltips.txt`, `code_tooltip_clear`.
