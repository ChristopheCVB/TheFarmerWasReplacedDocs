# `list`

`list(collection = None)`
Creates a new list. 
If `collection` is None, it creates an empty list.
If `collection` is any sequence, it creates a new list with the element of the sequence.

returns a list.

takes `1 + len(collection)` ticks to execute.

example:
`new_list = list((1,2,3))`
