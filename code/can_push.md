# `can_push`

`can_push(direction)`
Checks whether the block under the drone can be pushed.

returns `True` if the block under the drone can be pushed, `False` otherwise.

takes `1` tick to execute.

example:
`can_push(North)`

Source: `EN/Strings/code_tooltips.txt`, `code_tooltip_can_push`.
