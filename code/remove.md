# `remove`

`collection.remove(element)` 
Removes the first occurrence of `element` from the `collection`.

returns `None`

takes `element size` ticks to execute on a set, #comparisions + #shifts ticks on a list.

example:

```python
list = [True, False, None]
list.remove(False)
```
