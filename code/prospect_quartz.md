# `prospect_quartz`

`prospect_quartz()`
Use iron to look for quartz.

returns the euclidean distance (3D distance) from the drone to the next quartz block, or `None` if no quartz is nearby.

costs 1 iron to execute.

takes `1` tick to execute.

example:
`print(prospect_quartz())`
