# `get_pos_z`

`get_pos_z()` 
Gets the current z position of the drone.
The z position starts at `0` and decreases when you dig down.

returns a number representing the current z coordinate of the drone.

takes `1` tick to execute.

example:
`x, y, z = get_pos_x(), get_pos_y(), get_pos_z()`

Source: `EN/Strings/code_tooltips.txt`, `code_tooltip_get_pos_z`.
