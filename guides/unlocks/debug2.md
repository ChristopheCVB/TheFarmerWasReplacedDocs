# Debug 2

When your drone gets too fast and the grid gets too big, it can become hard to see what's going on.

For this reason, you can use the `set_execution_speed()` and `set_world_size()` functions.
They allow you to reduce the execution speed and the farm size. 

The farm size and the execution speed will be reset to the default values at the end of the execution.
